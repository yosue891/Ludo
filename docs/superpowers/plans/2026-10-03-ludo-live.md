# Ludo Live implementation plan

1. Build a dependency-free C++ rules engine with deterministic roll injection for tests.
2. Add tests for joining, starting, base exit, exact-home movement, capture, safe cells, extra turns and win state.
3. Wrap the engine in a Crow WebSocket room/session server.
4. Build typed frontend protocol models and reconnecting WebSocket client.
5. Build responsive lobby, room controls and 15×15 board with movable-token affordances.
6. Add design tokens, accessibility states and responsive layout.
7. Add CMake, Dockerfiles, compose configuration and CI.
8. Run backend tests plus frontend install/typecheck/build and fix failures before finalizing.
